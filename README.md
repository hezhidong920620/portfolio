## 🚀 本地开发

由于项目使用 CDN 引入依赖，无需安装任何包，直接在浏览器中打开 `index.html` 即可预览：

```bash
# 克隆项目
git clone https://github.com/hezhidong920620/portfolio.git

# 进入目录
cd portfolio

# 用浏览器打开（或启动本地服务器）
# 方式1：直接双击 index.html
# 方式2：使用 Python 简易服务器
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 📦 部署

本项目使用 **GitHub Actions** 自动部署到 GitHub Pages：

1. 推送代码到 `main` 分支
2. GitHub Actions 自动触发部署
3. 网站自动更新到 `https://hezhidong920620.github.io/portfolio/`
